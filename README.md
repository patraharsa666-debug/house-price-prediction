# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using Machine Learning (Linear Regression).

## Dataset
Housing Prices Dataset from Kaggle:
https://www.kaggle.com/datasets/yasserh/housing-prices-dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- GitHub

## Workflow
1. Load Dataset
2. Data Preprocessing
3. Encode Categorical Variables
4. Train-Test Split
5. Linear Regression Training
6. Model Evaluation
7. House Price Prediction

## Model Performance
- R² Score: 0.6529
- MAE: 970043
- RMSE: 1324506
